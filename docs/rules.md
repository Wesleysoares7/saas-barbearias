# Regras do Projeto

## Stack obrigatoria
- Next.js (App Router)
- TypeScript
- TailwindCSS
- shadcn/ui
- Supabase
- PostgreSQL
- Deploy alvo: Vercel

## Regras tecnicas
- Sempre usar TypeScript.
- Nao usar any.
- Priorizar Server Components quando possivel.
- Criar componentes reutilizaveis.
- Validar formularios.
- Tratar erros e estados de carregamento.
- Manter clean code e escalabilidade.
- Interface mobile first e responsiva.

## Regras de execucao
- Implementar uma funcionalidade por vez.
- Nao adicionar funcionalidades extras sem autorizacao.
- Atualizar documentacao a cada etapa.
- Nao quebrar funcionalidades existentes.
